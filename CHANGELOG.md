# Changelog
## [2.0.0] - 2026-10-02

### Added
- Long-press to reorder habits (Active and Inactive lists)
- Custom emoji as habit icons
- 12 fixed themes (Black, Charcoal, Midnight, Dark Forest, Dark Teal, Wine, Coffee, etc.)
- Notification on/off switch in Settings
- Rewritten haptics with strength slider

### Changed
- Database schema 4: added `emoji` and `sortOrder` columns
- Backups now include emoji and sortOrder

## 1.0.1
- Added a habit icon picker, and icons on the dashboard
- Added icons on the habit detail stats
- Added a "Viewing <date>" bar with a "Back to today" button on the home screen
- Added light vibration feedback when voting
- Added the app version at the bottom of Settings
- Added an empty-state message when there are no active habits
- Create and Restore backups now use the system file browser
- Daily reminder notification and theme color presets
- The app now starts even if notification setup fails
